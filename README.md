# Haroon Shirzad — Official Portfolio & AI Laboratory

> *"I don't just use AI tools. I build systems with them."*

A world-class, production-ready developer portfolio and AI laboratory built for **Haroon Shirzad** — AI Developer, Builder, and Technology Explorer.

---

## 🌟 Key Features & Architectural Highlights

- **Dark Futuristic Laboratory Aesthetic**: Deep space background with an interactive real-time HTML5 Canvas neural constellation, subtle glow accents, glassmorphic panels, and smooth micro-interactions.
- **Authentic & Factual Builder Profile**: No fabricated degrees, companies, clients, or awards. Clean data architecture with explicit placeholders (`[ADD GITHUB URL]`, `[ADD EMAIL]`) for easy customization.
- **Complete Project Showcase**:
  - **BakhterGPT**: Multi-model Flutter AI application with Google Gemini, DeepSeek, and OpenAI integration, multimodal vision, Firestore persistence, and educational communication workflows.
  - **The Secrets of Universe**: Flutter astronomy application with planetary telemetry, celestial catalog, and NASA imagery.
  - **Perfect Wallpaper**: Android wallpaper utility built with Flutter and native MethodChannels.
  - **Sound Flow**: Dark-themed Afghan music exploration concept (Ahmad Zahir, Sarban, Nashenas, Farhad Darya, Zahir Howaida, Qais Ulfat, Saida Gul Mina).
  - **فرار از میر آغا (Escape from Mir Agha)**: 2D arcade evasion game built with Flutter's CustomPainter canvas engine at 60fps.
  - **Hospital AI Concept**: Clinical multi-agent intelligence and hospital workflow blueprint.
  - **AI Employment Concept**: Conversational voice/text skill discovery and economic matching blueprint.
  - **Autonomous AI Assistant (Jarvis Concept)**: Experimental voice, computer control, and hardware actuation prototype.
- **Interactive AI Technology Matrix**: Categorized inspection of AI (LLMs, Agents, Vision, Voice), Mobile (Flutter, Dart), Backend (Firebase, Firestore), Automation (n8n, Webhooks), and Frontier Models (Gemini, DeepSeek, OpenAI, Claude).
- **AI Lab Sandbox**: Dedicated research logs detailing hypotheses, empirical findings, and roadmaps for multi-agent workflows, Claude Code automation, local voice models, and robotics.
- **Currently Exploring Radar**: Live status indicators for ongoing technical sprints.
- **Knowledge Base & Articles**: SEO-optimized technical blog architecture with reading times, tags, and Schema.org `BlogPosting` schemas.
- **Generative Engine Optimization (GEO) & Machine Entity Graph**:
  - Full Schema.org JSON-LD graph (`Person`, `WebSite`, `SoftwareApplication`, `BlogPosting`, `BreadcrumbList`).
  - Native `/llms.txt` and `/llms-full.txt` files for AI answer engines (Perplexity, ChatGPT Search, Claude).
  - Open AI crawler permissions in `robots.txt` for `GPTBot`, `ClaudeBot`, `PerplexityBot`, `Applebot`.
  - Machine-readable Semantic FAQ and Entity Knowledge Explorer.
- **Command Palette (`⌘K` / `Ctrl+K`)**: Instant keyboard search across all projects, technologies, experiments, and articles.
- **Sub-Second Performance & Accessibility**: 105 kB shared JS, WCAG compliant contrast, keyboard navigation, and reduced-motion support.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, Server-Side Prerendering / SSG)
- **Language**: [TypeScript](https://www.typescriptlang.org/) (Strict Type Safety)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom cyber/glassmorphism design tokens
- **Icons**: [Lucide React](https://lucide.dev/)
- **Visuals**: Custom Interactive HTML5 Neural Constellation Canvas (Zero heavy WebGL dependencies)

## 🚀 Quick Start

### 1. Install Dependencies
\`\`\`bash
npm install
\`\`\`

### 2. Start Development Server
\`\`\`bash
npm run dev
\`\`\`
Visit `http://localhost:3000` to view the application.

### 3. Run SEO & GEO Compliance Audit
\`\`\`bash
npm run audit:seo-geo
\`\`\`

### 4. Build for Production
\`\`\`bash
npm run build
\`\`\`

## 🌐 Deploying to Production

This project can be deployed instantly to any modern hosting provider:

### Deploying to Vercel (Recommended)
1. Push this repository to GitHub/GitLab.
2. Import the repository into [Vercel](https://vercel.com).
3. Vercel will automatically detect Next.js and deploy with optimal edge caching and SSL.

### Deploying to Cloudflare Pages / Netlify / Static Hosts
Run `npm run build` to generate the static build, and deploy the `.next` or static export output.
